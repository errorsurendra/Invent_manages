## 📖 Project Overview

Project FORESIGHT is an AI-powered inventory management platform developed to help businesses improve stock planning and supply chain efficiency.

The system analyzes historical sales data, predicts future demand, detects stock shortages and overstock situations, and provides actionable inventory recommendations through an interactive Streamlit dashboard.

The objective is to reduce inventory costs, prevent lost sales, and support data-driven inventory planning.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/errorsurendra/Invent_mang.git
```

Navigate to the project

```bash
cd Invent_mang
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
